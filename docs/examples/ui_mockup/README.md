# 실제 HTML 목업 예시

이 폴더는 **UI 명세를 작성한 뒤 AI로 생성할 수 있는 정적 HTML 목업의 예시**입니다.

## 포함 프로그램

- PG-01 학생 홈/평가 현황
- PG-02 팀 평가 대상 목록
- PG-03 팀 평가 입력
- PG-04 개인 평가 대상 목록
- PG-05 개인 평가 입력
- PG-06 평가 제출 현황

## 시작 방법

`ui_index_example.html`을 브라우저에서 엽니다.

권장 확인 순서:

```text
학생 홈
→ 팀 평가 대상 목록
→ 팀 평가 입력
→ 평가 제출 현황
→ 개인 평가 대상 목록
→ 개인 평가 입력
```

## 주의

이 HTML은 정답이나 최종 구현 코드가 아닙니다.

- 실제 DB 저장 없음
- Django Template 문법 없음
- 로그인 세션 없음
- 서버 권한 검증 없음

실제 Django 개발 시에는 BR-01, BR-04, BR-05를 View/Service/DB 제약조건 등에서 다시 검증해야 합니다.
